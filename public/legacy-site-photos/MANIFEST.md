# AFS Legacy Site Photography — Manifest

Source: live legacy WordPress site, `https://www.architecturalflashingsupply.com/`
Imported: 2026-09-04 (afs-fl-036)

This library contains **46 genuine AFS project/product photographs**, pulled
directly from the legacy site's WordPress Media Library (via its public
`/wp-json/wp/v2/media` REST endpoint, cross-checked against every live page)
and verified image-by-image by actually looking at each one. It deliberately
excludes all licensed stock photography, third-party supplier logos, AFS's
own current brand assets, and generic design/background graphics that were
also present in the same media library. See "Excluded from this import"
below for the full accounting.

Every description below was written after opening the actual image, not
inferred from its filename.

  `green-tiles-roof-background-...-utc.jpg` above, just re-uploaded under an
  innocuous filename without the `-utc` tag. Confirmed stock; excluded
